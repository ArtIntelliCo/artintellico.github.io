# artintellico.com

Одностраничный сайт ArtIntelliCo на Astro в тринадцати вариантах оформления, у каждого
три локали: украинская без префикса, русская в `/ru/`, английская в `/en/`.

| Вариант | Адрес (uk) | Исходники |
|---|---|---|
| Norton Commander (основной) | `/` | `src/variants/nc/` |
| Классический сайт | `/classic/` | `src/pages/classic/`, `src/components/` |
| Apple ][, DOS, Apple Lisa, UNIX, Windows 3.11, Midnight Commander, Linux, AI | `/apple/`, `/dos/`, `/lisa/`, `/unix/`, `/win31/`, `/mc/`, `/linux/`, `/ai/` | `src/variants/<id>/` |
| Windows NT 4.0, сайт 90-х, сайт 2010-х | `/winnt/`, `/web90/`, `/web2010/` | `src/variants/<id>/`, тексты — из словарей |

Список, порядок и адреса вариантов — `src/variants/index.ts`.

Ретро-вариант — это бывшая самодостаточная HTML-страница, разложенная на
`style.css`, `markup.html` и `script.js` (шрифты лежат в `public/fonts/`).
Страницу вокруг неё собирает `src/layouts/Variant.astro`: SEO-заголовки,
текст сайта в `<noscript>` для поисковиков и футер `VariantBar.astro` со слоганом
и ссылками на все варианты. Чтобы под вариантом поместился футер, в его стилях
`100vh` заменены на `var(--aic-vh)` (см. `src/variants/frame.css`).

Язык хранится в `localStorage` (`aic-lang`). Адреса `/ru/…` и `/en/…` задают
язык явно, адреса без префикса открываются на последнем выбранном языке.
Когда язык меняют внутри варианта, адрес страницы меняется вслед за ним.

## Разработка

    npm install
    npm run dev

## Проверки

    npm run check   # типы и разметка Astro
    npm test        # сборка + проверки готового HTML

## Тексты

Эталонные тексты — в `src/i18n/{uk,ru,en}.json`: по ним собраны классический сайт,
текст ретро-вариантов для поисковиков, слоган и подписи футера. Описания услуг там
расширенные: лид, абзац о задаче, «Что входит», «Результат».

Ретро-варианты не копируют эталон, а пересказывают его в форме своего интерфейса:
man-страницы в UNIX, RPM-пакеты в Linux, справка WinHelp в Windows 3.11, вкладки
«Свойства» в Windows NT, служебные записки в Lisa и т. д. Эти тексты лежат в
`script.js` каждого варианта, поэтому при изменении услуг их нужно переписать и там.
`winnt`, `web90` и `web2010` при отсутствии своего текста берут его из словарей
через `window.AIC.content` (`src/variants/content.ts`).

Украинский словарь задаёт структуру: если в русском или английском не хватает ключа, `npm run check`
падает. Разметка страницы одна на все локали — три файла в `src/pages/`
отличаются только переданной локалью.

Порядок услуг задаётся в `src/data/services.ts`, сами тексты — в словарях.

## Деплой

Пуш в ветку `master` запускает GitHub Actions, которые собирают сайт и
публикуют его на GitHub Pages. Собирать и заливать вручную не нужно.

В настройках репозитория источник Pages должен быть переключён на
«GitHub Actions» — иначе сборка пройдёт, а публикация нет.

История Middleman-версии сайта доступна в теге `legacy-middleman-build`.
